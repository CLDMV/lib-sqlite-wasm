# @cldmv/sqlite-wasm

SQLite compiled to WebAssembly for Node.js and browsers, with file storage on disk and in OPFS. This package is early and under design: the public API is not defined yet, and the current release only exports a placeholder.

## Install

```sh
npm install @cldmv/sqlite-wasm
```

Requires Node.js `>=20.19.0` at runtime. Working on the repository itself needs Node.js `>=22.22.0`.
