# `@cldmv/sqlite-wasm` v0.2.3 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/0.2.3`

---

## Overview

CI now cancels superseded runs on `next` and `hotfixes`, so a burst of pushes no longer leaves every older run going. No runtime code changed: the published package is the same as v0.2.2 apart from the version number.

---

## 🔧 CI & tooling

### Cancel superseded CI runs on next and hotfixes ([#22](https://github.com/CLDMV/lib-sqlite-wasm/pull/22))

`ci.yml` now carries the `concurrency` block from CLDMV/.github v4.46.0. Only the release base branch gets a unique group per run and is never cancelled. Everything else, including feature branches and PRs, `next`, `hotfixes` and the release PRs from them, uses a per-ref group with `cancel-in-progress`, so the newest commit's run replaces the older ones. Before this, runs on `next` and `hotfixes` were never cancelled and could hold a large share of the org's hosted runner slots.
