# `@cldmv/sqlite-wasm` v0.2.2 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/0.2.2`

## Overview

CI now builds and tests on macOS, on Apple Silicon and Intel, as well as on Linux. No runtime code changed: the published package is the same as v0.2.1 apart from the version number.

---

## 🔧 CI & tooling

### Build and test on macOS ([#18](https://github.com/CLDMV/lib-sqlite-wasm/pull/18))

The wasm build downloads per-platform wasi-sdk and binaryen and uses the host `make` and `cc`, so a Linux-only check can't tell whether it still works on a Mac. `ci.yml` now sets `extra_build_os` to `["macos-latest", "macos-15-intel"]`, which adds a build-and-test leg on Apple Silicon and one on Intel through the shared workflow from CLDMV/.github v4.46.0.
